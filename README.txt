FRUTI KRUTI Mini App
=====================

Это стартовая версия интерфейса Telegram Mini App:
- Главная
- Кейсы
- Лидеры
- Профиль
- Нижняя навигация
- Чтение имени пользователя из Telegram WebApp

Важно: это пока интерфейс-прототип. Игры, реальный баланс, платежи, база данных и серверная проверка Telegram initData добавляются следующим этапом.

Для Telegram нужен HTTPS URL, на котором доступен index.html.
